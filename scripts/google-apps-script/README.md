# Google Apps Script 설정 가이드

관리자 페이지가 문의 내역을 조회·수정하려면 기존 Apps Script를 아래 코드로 **교체**한 뒤 **새 버전으로 재배포**해야 합니다.

## 1. 코드 붙여넣기

1. Google Sheets → **확장 프로그램** → **Apps Script**
2. 기존 코드를 `Code.gs` 내용 전체로 교체
3. 저장

## 2. Script Properties 설정

1. Apps Script 좌측 **프로젝트 설정** (톱니바퀴)
2. **스크립트 속성** → 속성 추가
3. `ADMIN_API_KEY` = 임의의 긴 비밀 문자열 (관리자 `.env`와 동일하게 설정)

## 3. Web App 재배포

1. **배포** → **새 배포** → 유형: **웹 앱**
2. 실행: **나**
3. 액세스: **모든 사용자**
4. 배포 후 URL 복사 → 랜딩/관리자 `.env`의 `GOOGLE_SCRIPT_URL`에 설정
